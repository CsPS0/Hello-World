# Agent Rules

Shared rules for every coding agent working in this repository (Claude, Gemini, Codex, Cursor and others).

## Conduct

1. Answer in English in the chat or session.
2. Prefer Serena MCP for finding files, reading and editing code. If an MCP is out of credits or fails, fall back to the built-in finder and editor tools.
3. Compile, run and debug the code before finishing a request. `bun run build` and `bunx tsc --noEmit` must pass. Check UI changes in the browser with `bun run dev`.

## Design

4. Avoid typical "modern" vibecoded website design: glassmorphism, neon glow accents, gradients, pill cards, floating panels, Outfit or Inter typography, unnecessary animation.
5. Keep designs clean, fast, information-dense and content-first, in a terminal-inspired, classic retro or brutalist monospace style.

## Project

- Static site in `docs/`, served by `index.ts` (Bun). `bun run dev` serves with hot reload, `bun start` without.
- `docs/languages.json` is generated by `docs/build.js` from `docs/hello-world/` and `docs/language_metadata.json`. Never edit it by hand; run `bun run build`.
- `bun run check` rebuilds and fails if `languages.json` is out of date. CI runs it.
- To add a language: add `docs/hello-world/hello.<ext>`, add the extension to `EXTENSION_MAP` (or `FILENAME_MAP` for shared extensions), `DESCRIPTION_DEFAULTS` and `PRISM_MAP` (syntax grammar; custom ones live in `docs/prism-extra.js`) in `docs/build.js`, add an entry to `docs/language_metadata.json` (with `website` when the language has its own site), add `docs/icons/<slug>.svg`, then rebuild and update the language count in `README.md` and `docs/index.html`. See `CONTRIBUTING.md` for the slug rules and metadata schema.
- The FAMILY TREE tab is built from `influencedBy` in `language_metadata.json` (names of languages on the site, with `influenceSources`); build.js derives the reverse `influenced` lists and fails on unknown names. Only list influences released before the language.
- Icons are single-colour SVGs drawn as CSS masks in the theme colour. Framework icons live in `docs/icons/frameworks/` and are referenced from `frameworks_metadata.json`.
- Check every website URL with a real request before adding it, and check that a logo or website belongs to the language and not to a same-named product.
- Every sample prints a hello world, with no comments. Prefer exactly `Hello, World!`; any other hello world output (other capitalisation, or with a prefix such as `ECHO:`) is allowed when that is what the language produces, and the history text says what it prints.
- Escape any data from JSON with `escapeHTML` before putting it in `innerHTML`.
- The Stack Finder tab reads its catalog and scoring from `docs/wizard-stacks.js` (pure data + functions, no DOM). Each stack's `lang` must match a name in `languages.json`; setup commands must be official ones you have checked.
- Never add `Co-Authored-By` trailers, "Generated with" lines or any other AI attribution to commit messages or pull request descriptions.
- Keep line endings LF (`.gitattributes` enforces it).
