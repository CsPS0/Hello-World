# Agent Rules

Shared rules for every coding agent working in this repository (Claude, Gemini, Codex, Cursor and others).

## Conduct

1. Answer in English in the chat or session.
2. Prefer Serena MCP for finding files, reading and editing code. If an MCP is out of credits or fails, fall back to the built-in finder and editor tools.
3. Compile, run and debug the code before finishing a request. `bun run build` and `bunx tsc --noEmit` must pass. Check UI changes in the browser with `bun run dev`.

## Design

4. Avoid typical "modern" vibecoded website design: glassmorphism, neon glow accents, gradients, pill cards, floating panels, Outfit or Inter typography, unnecessary animation.
5. Keep designs clean, fast, information-dense and content-first, in a terminal-inspired, classic retro or brutalist monospace style.

## Project

- Static site in `docs/`, served by `index.ts` (Bun). `bun run dev` serves with hot reload, `bun start` without.
- `docs/languages.json` is generated by `docs/build.js` from `docs/hello-world/` and `docs/language_metadata.json`. Never edit it by hand; run `bun run build`.
- `bun run check` rebuilds and fails if `languages.json` is out of date. CI runs it.
- To add a language: add `docs/hello-world/hello.<ext>`, add the extension to `EXTENSION_MAP` (or `FILENAME_MAP` for shared extensions) and `DESCRIPTION_DEFAULTS` in `docs/build.js`, add an entry to `docs/language_metadata.json`, then rebuild. See `CONTRIBUTING.md`.
- Every sample prints exactly `Hello, World!`, with no comments.
- Escape any data from JSON with `escapeHTML` before putting it in `innerHTML`.
- Never add `Co-Authored-By` trailers, "Generated with" lines or any other AI attribution to commit messages or pull request descriptions.
- Keep line endings LF (`.gitattributes` enforces it).
