SKIPPED LANGUAGES
=================

Languages that were considered for the site but not added, and why.
Each one could be added later if the missing piece is found.

To add one, follow CONTRIBUTING.md. Every language needs: a sample that
prints a hello world (any form is fine), the creator, the date of the first
public release, and 1-3 sources that back those facts up.


1. ONE FACT SHORT
   The language is fine, but a required fact could not be backed by a
   source. These are the easiest to add: find the missing fact.

   Missing the first public release date:
   - Agena              first-release year could not be verified
   - Brat               brat-lang.org no longer resolves; repo dates from 2009-04-20, no releases (Justin Collins)
   - Clay               the 0.1.0 "first release" post (2012-01-16) mentions earlier versions (KS Sreeram)
   - Cognate            only nightly builds, no dated release
   - Dao                the 2006 1.0-beta post says "as before", so earlier releases exist
   - DCL (OpenVMS)      no source names a first-release date
   - DM (BYOND)         no dated first public release (Dan Bradley, Tom Hehre)

   - Hoon               only 2011/2013 claims, creator not confirmed

   - KQL                public earlier as Application Insights Analytics (AIQL), that date not found
   - Murex              earliest GitHub release is v2.2.1200 (2021); the changelog may give an earlier date (Laurence Morgan)
   - Myrddin            the r0.1.0 tag is on a 2017 commit, but the language is older (Ori Bernstein)

3. TECHNICAL REASONS
   - ><> (Fish)         its name cannot be turned into a page link
   - /// (Slashes)      its name cannot be turned into a page link
   - ALGOL 60, JOVIAL   no standard input/output; hello world depends on the compiler
   - Assembly (MMIX)    release date ambiguous (designed 1999, stable 2011)
   - B4X                goes back to the undated Basic4ppc; Log() needs a Sub around it
   - Bend               being rewritten as "Bend 2"; hello world syntax is still changing
   - CSS                shows nothing without a host HTML page (CSS1 Recommendation: 1996-12-17)
   - ACL2               the sample only works in its REPL; only a year (1996) is sourced
   - Huginn             site certificate expired; no release date; sample same as Pawn
   - JavaFX Script      no release date, and its hello world opens a window
   - Lox                no first public release date (from the book "Crafting Interpreters")
   - MAD, RATFOR, PL/M, TECO, SASL, Isabelle
                        output or sample could not be verified (printer control
                        codes, Fortran I/O, CP/M boilerplate, control characters,
                        unusual quoting, value display)
   - Modelica           has no documented print-style hello world
   - Natural            no source could be loaded
   - Pod (Perl)         no source dates it or names its creator
   - QuakeC             runs only inside the Quake engine
   - sed                prints nothing without input
   - troff              no source dates Ossanna's troff
   - Whiley, Tailspin   only outdated samples found
   - YAMLScript         unclear whether the 2022 Perl version is the same language as today's
